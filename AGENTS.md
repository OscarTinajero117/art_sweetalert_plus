# AI Agent Guidelines for Art SweetAlert Plus

Welcome to the `art_sweetalert_plus` project! When interacting with this codebase, please adhere to the following rules to maintain consistency and professionalism:

1. **No Emojis:** Do not use emojis in comments, documentation, or commit messages. Keep the tone strictly professional.
2. **Testing:** Any new features or bug fixes must be accompanied by relevant widget or integration tests.
3. **Modern UI/UX:** When updating the UI components, prioritize modern design principles, such as appropriate border radii, proper elevation, smooth animations, and ripple effects (using `Material` and `InkWell`).
4. **Adaptive Theming:** Components should automatically adapt to the user's system theme (Light/Dark mode) when possible, utilizing `Theme.of(context)` for colors.
5. **Code Style:** Follow the standard Dart style guide. Run `flutter analyze` and `flutter format` before finalizing changes.
